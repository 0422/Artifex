## 📌 TL;DR（执行摘要）

- **核心目标**：为自驱型博学者（25-40岁，同时学习2+领域）构建一个全领域AI学习伙伴，打破外语学习（Duolingo）、知识管理（Notion/Obsidian）、间隔复习（Anki）之间的"学-记-用"断裂，实现从内容摄入到智能复习到输出练习的完整闭环，一个Agent管三个领域。
- **关键决策**：产品命名为"Artifex"，采用IIROR深度习得模型（汲取→内化→保持→产出→精进），不做游戏化、不做社交网络、不做AI代写。MVP=5项P0需求，16周（含2周buffer建议），首发英日双语+3个高频场景。V1.1新增桌面数字人语音交互（P1-6），为AI Agent赋予可视化虚拟形象。
- **差异化定位**："全领域学习操作系统"——Duolingo/Anki/Notion/Readwise/ChatGPT各自只覆盖学习链条的一环，Artifex 把它们连起来并加上AI记忆。核心差异：(1)学完自动进入复习系统零手动；(2)AI对话练习自然引出知识点；(3)统一跨领域仪表盘。
- **下一步**：解决3个阻塞性技术预研（PWA vs 原生/STT-TTS选型/AI成本模型），启动M1开发（内容捕获+引导对话+前端框架）。

## 3. 用户研究洞察（来自瑞思）

### 三类学习者的核心差异

| 维度 | 外语 | 人文社科 | 兴趣技能 |
|------|------|---------|---------|
| 核心瓶颈 | B1→B2：从"能说"到"说好" | "只进不出"：大量输入≠内化 | 平台期：卡住了不知道为什么 |
| 最大恐惧 | 开口丢脸 | 讲不清楚 | 永远"差不多" |
| 最佳激励 | 完成真实对话的成就感 | 讲清楚一个复杂概念 | 听到/看到进步的客观证据 |
| 最适复习 | FSRS, retention=0.90 | 概念簇复习, retention=0.85 | 陈述性知识FSRS + 程序性"距上次练习天数" |

### 五大设计原则

1. **进步显微镜**：不打分不排行，用数据让微小进步可见
2. **"你的下一步"**：打开第一眼看到的永远是当前最有价值的事
3. **说对确认，说错轻轻纠正**：不给压迫感但给有用感
4. **有人陪你走**：Agent了解你的历史、记得你的困难
5. **你只管学，怎么学我来想**：扛走全部元认知负担

### 从研究到功能的映射

"安全的口语输出环境" → P0-3检验对话 / "读完就忘" → P0-1+P0-2 / "卡住了不知道为什么" → P1-2音频分析 / 6个月流失 → Non-goal:不做游戏化 / "收藏即学会" → P0-3检验对话（费曼式）

## 4. 竞品对比（来自竞析）

### 六家竞品 × 五个断裂点

| 断裂点 | 现状 | Artifex 的修复 |
|--------|------|-----------|
| **学-记断裂**（最严重） | Duolingo→Anki需手动制卡，99%用户不做 | 学到的一切自动进入复习，零手动 |
| **记-用断裂** | Anki只测记忆不测应用 | 复习卡片自然引出对话/解释/演示 |
| **领域孤岛** | 法语用Duolingo、哲学用Obsidian、吉他看YouTube | 一个Agent统一管理，用最适方式辅助 |
| **AI浅层应用** | ChatGPT每次从零开始 | Agent记住全部学习历史，对话连续 |
| **动机断崖** | Duolingo连胜在"严肃学习"中消失 | 以"可感知的进步"而非游戏化为基础 |

### 竞争定位陈述

> 对于同时学习多个领域的自驱型成年人，Artifex 是一个AI学习伙伴。它不同于Duolingo/Anki/Notion这类单一环节工具，因为它覆盖了从内容摄入、知识组织、智能复习到输出练习的完整学习循环——而且一个Agent管三个领域。你得到的不是一个更好的抽认卡App，而是一个了解你、记得你、推动你的学习伙伴。

## 5. 数据依据（来自数析）

### IIROR 深度习得模型

| 阶段 | Agent做什么 |
|------|-----------|
| **汲取** Intake | 自动捕获内容、提取关键概念；新资料由 LLM 自动归位到路径对应环节 |
| **内化** Internalize | 自动生成卡片、建立知识图谱 |
| **保持** Retain | FSRS自动调度、跨领域去重 |
| **产出** Output | 对话式费曼检验：通过谈论检验掌握程度，加深理解与输出 |
| **精进** Optimize | 检验结果驱动路径实时更新、薄弱点分析、突破计划、版本对比 |

### 北极星指标

| 领域 | 北极星 | 定义 |
|------|--------|------|
| 外语 | **ELTB** | 可用语言任务广度（按CEFR分级） |
| 人文 | **KGV** | 知识图谱活度（新连接速率+重激活率+跨域占比） |
| 兴趣 | **SAC** | 技能可达高度（里程碑覆盖率+实践难度分） |
| 跨领域统一 | **DLE** | 日均学习效能（有意义事件×深度/总时间） |

### 动力健康度 MHI

- MHI = 0.30×一致性 + 0.25×投入度 + 0.25×进展感知 + 0.20×情绪
- 🟢健康 → 🟡注意（3天空白）→ 🟠警告（7天5天空白）→ 🔴危险（14天空白）
- 自动检测5种不健康模式：冲刺-崩溃、单维度偏食、完美主义瘫痪、漫游迷失、虚假忙碌

#### P1-6 桌面数字人语音交互 — 详细规格

**需求描述**：为 AI Agent 提供可视化虚拟形象（桌面数字人），支持语音驱动的双向交互。数字人作为检验对话（P0-3）和日常学习陪伴的视觉前端，强化"有人陪你走"的设计原则。

**核心验收标准**：
- 虚拟形象渲染：WebGL 驱动的 3D/2D 角色在桌面端 60fps 流畅渲染；支持闲置动画（眨眼/呼吸/微动作）
- 语音输入：点击或唤醒词触发语音录入，STT 转写延迟 ≤ 500ms（本地 Whisper）/ ≤ 1.5s（API）
- 语音输出：TTS 合成语音驱动口型同步（lip-sync），偏差 ≤ 80ms
- 表情系统：至少 6 种上下文表情（neutral/happy/thinking/encouraging/apologetic/celebrating），根据对话语义自动切换
- 浮动模式：支持最小化为桌面悬浮小组件（120×120px），在其他学习任务中持续陪伴
- 领域感知：数字人角色根据当前学习领域切换形象/语调（如日语场景切换和风角色）

**与现有需求的关系**：
- 依赖 P0-3（检验对话）：数字人是检验对话的可视化前端
- 依赖 P0-2（记忆系统）：复习时数字人可语音播报卡片
- 增强 P1-4（动力预警）：数字人可通过表情/语气传递 MHI 状态反馈

## 7. 关键用户流程图

### 领域学习流程（核心主线）

```
[添加领域] → [问卷:起点分析+目标分析] → [生成路径(有序里程碑序列)]
                                              ↓
                        [推荐学习资料+用户手动添加] → [LLM自动归位到路径对应环节]
                                              ↓
                        [用户外部自学——主体在软件外，Artifex 不托管学习内容]
                                              ↓
                        [对话式费曼检验] → [检验报告:薄弱点+新卡片]
                                              ↓
                        [FSRS调度复习] → [路径实时更新:推进/重排里程碑]
                                              ↓
                        [回到当前里程碑 → 重新生成今日任务]
```

### 日常学习循环

```
[打开 Artifex] → [今日学习: 当前里程碑任务 + 待复习 + 推荐下一步]
                ├─ 复习 → P0-2记忆系统（数字人可语音播报卡片）
                ├─ 检验 → P0-3检验对话（外语场景对话/人文费曼/兴趣练习汇报）
                ├─ 资料 → P0-1资料组织（推荐+自动归位）
                ├─ 路径 → P0-5领域路径（里程碑状态，检验驱动更新）
                ├─ 探索 → 查看概念地图
                └─ 数字人 → P1-6 悬浮陪伴模式（V1.1）
                            ↓
                [完成学习事件] → [更新FSRS/路径/MHI/DLE] → [日终小结]
```

## 8. Non-goals（明确不做什么）

### 绝对不做

| 项目 | 理由 |
|------|------|
| 游戏化激励机制（连胜/排行榜/积分） | 6个月后大量流失；目标用户是严肃自驱学习者 |
| 社交网络功能（公域动态流/点赞/评论） | 社交比较焦虑是自学者痛苦源。P2学习圈是私密小群 |
| UGC课程/内容市场 | Artifex 是学习伙伴不是内容平台 |
| AI代写/代做 | 与"AI不替代思考"原则根本冲突 |

### v1不做（P2或更晚）

多设备同步、离线模式、团队/班级模式、第三方内容集成、自定义FSRS参数面板、内置课程/视频播放

> **注**：P1-6桌面数字人模块不是独立的原生桌面应用，而是PWA内的WebGL浮层组件。"原生桌面应用"（如Electron/Tauri打包的独立桌面客户端）仍为Non-goal。
